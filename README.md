FocusBalm
A student productivity app built around one idea: every completed focus session becomes a lip balm tube on a collectible shelf.
Live app: https://focusbalm.lovable.app

Pomodoro timer for focus sessions
Distraction tracking during sessions
Streak system to reward consistency
GPA tracker
Weekly calendar
Collectible shelf: completed sessions fill a shelf with lip balm tubes
Tech
React, TypeScript, Supabase.
How it was built
I built FocusBalm with Lovable and AI assistance, designing the features and the shelf concept and iterating on the result. It was my first project in this stack.
